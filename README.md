# ZIP — Night Run

An original comic-style scroll story. Characters (Zip and Static) and story are original; the look is inspired by the stylings of modern animated comics (halftone dots, off-register colour, caption boxes).

Built with Vite, GSAP + ScrollTrigger, Lenis and the Web Audio API.

```bash
pnpm install
pnpm dev      # http://localhost:5300
pnpm build
```
